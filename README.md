# 🎨 Van Gogh Sticker

Um bot de WhatsApp para criar figurinhas personalizadas a partir de imagens enviadas pelos usuários. Transforme suas fotos em stickers de forma rápida e fácil!

## 🚀 Funcionalidades
- Criação automática de figurinhas a partir de imagens (JPG, PNG, WEBP)
- Comando `!figurinha` para ver o menu de ajuda
- Detecção automática de mídia
- Respostas amigáveis e informativas
- *(Em breve)* Suporte a GIFs e vídeos curtos para figurinhas animadas
